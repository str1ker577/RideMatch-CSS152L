What's New with RideMatch!

For our CSS152L group project, we are continuing the development of RideMatch — now introducing a wave of exciting new features and improvements based on your feedback and evolving user needs.

Patch 1.0.1 - Updated Login/Sign up feature

- Fixed issue where users couldn't login even with valid credentials.

- Added a user profile icon next to the the Navigation Bar's top right, this way users can toggle to sign out of their accounts.

- Improved backend error handling for smoother user authentication.

- Added a login button to the top right of the naviation for easier access.

- The User Icon in the sidebar now functions contextually.

  • • When logged in, it takes you to your profile page.
  • • If not logged in, it prompts you to login or sign up.
May 31st, 2025

Patch 1.0.2 New Pages & Layout Foundation

- Introduced several new core pages as part of RideMatch's expanded functionality:

  • • Forum - A dedicated space for users to ask questions or share car-related discussions.
  • • Patches/What's New - A changelog-style page to keep users informed about recent updates.
  • • Profile - Personlized profile pages for each registered user.

- All new pages use a consistent layout for a seamless browsing experience.

- Updated the side navigation menu to include links to the newly added pages, making navigation easier and more intuitive.

June 1st, 2025

Patch 1.0.3 Added Fully Electric Option and Added Electric Cars to the database

- Introduced a new “Fully Electric” filter option in the car search function. Expanded the vehicle database to include electric car specifications.

June 6th, 2025

Patch 1.0.4 Added Calculator Page and Calculator Icon to the sidebar

- Created a new Calculator.html and added the default header and footer layout.

- Added a new Icon to the side bar menu that takes you to the calculator page.

June 6th, 2025

Patch 1.0.5 Added Sorting Dropdown box in Results Table

- Implemented a dropdown filter in the results table header using a filter icon.

  • • Users can now sort by Price (Low to High / high to Low).
  • • Users can now sort by Horsepower (Low to High / high to Low).
  • • Users can now sort by Cargo Space (Low to High / high to Low).
  • • Users can now sort by Price (Low to High / high to Low).
Date June 7th, 2025

Patch 1.0.6 Updated Results Table

- Improved table layout and text display for better readability and user experience.

  • • Implemented intelligent text wrapping for longer content in all columns.
  • • Optimized column width distribution for better space utilization.
  • • Enhanced dropdown filter positioning to eliminate unwanted whitespace.
  • • Added alternating row colors for improved table readability.
  • • Implemented hover effects for better row identification.
  • • Improved mobile responsiveness with better column sizing.
  • • Enhanced vertical content alignment for cleaner appearance.

- Added corresponging Icons for Car Fuel-Type for better visualization and calrity.

  • Electric – shown in RideMatch gold
  • Gasoline – brigh red to represent fuel
  • Diesel – industrial steel gray
  • Hybrid – muted green to represent eco-friendliness

- Introduced a new utility feature to improve filtering usability.

  • • Added a "Reset Filters" button that clears all active filters and restores default car listings.
  • • Helps users quickly return to the full results without manually deselecting filters.
Date June 8th, 2025

Patch 1.0.7 Implemented the Testimonial Page functionality

- Initialized Firebase Realtime Database to store users testimonials as well as any other user information for future integration.

- Created the testimonial form for users to input their titles (optional) and their testimonal.

- Users can now add and submit their testimonials.

- User testimonals can be seen by other users.

- Submissions are saved to Firebase Realtime Database and rendered dynamically as testimonal casds.

- Each testimonial displays:

  • • Username
  • • Message Content
  • • Timestamp of submision
Date June 10th, 2025

Patch 1.0.8 Enhanced Car Affordability Calculator with Results Display

- Completed the Car Affordability Calculator functionality with comprehensive loan calculations and budget analysis.

- Implemented dedicated car results table that displays affordable vehicles within user's calculated budget.

- Added affordability scoring system with visual indicators (Excellent, Good, Fair, Tight) based on budget utilization.

- Enhanced calculator with automatic number formatting using commas for better readability of large numbers.

- Separated calculator styling into dedicated CSS file to prevent conflicts with main filter functionality.

- Calculator results table features:

  • • Fixed header that stays visible while scrolling
  • • Displays Brand, Model, Variant, Fuel Type, Price, and Affordability level
  • • Centered alignment for Price and Affordability columns
  • • Consistent column spacing and professional styling
  • • Hover effects and visual feedback

- Improved calculator form layout and spacing for better user experience.

- Fixed peso sign positioning to external placement preventing input field overlap.

- Added independent filtering system specifically for calculator that doesn't interfere with main car filter page.

Date June 15th, 2025

- Complete overhaul of the forum system with Reddit-style functionality and enhanced user experience

  • • Added loading states and error handling for better user feedback
  • • Integrated with existing Firebase authentication system
